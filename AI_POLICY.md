# AI Contribution Policy (AI_POLICY.md)

Tahoma2D will not accept any PRs and code significantly or purely generated by AI. Any PR suspected of this will be immediately closed without any discussion or consideration.

Code generated by AI may use or may be derived from GPL licensed sources. If questioned and confirmed, it would subject this project to GPL license obligations or we would need to remove the code. We wish to retain the freedom associated with a BSD-3 license as much as possible and avoid putting us into a position where we must remove code.

Furthermore, we respect and value the effort, the insights, and the innovations an experienced human developer can provide over some algorithm that has been trained to reuse and rehash code. Vibe coders can find other repos to play around in.

Use of AI as an aid for a human developer is not strictly prohibited. It can still be a powerful tool for analysis, providing some insights on troubling problems, and performing repetitive time consuming tasks. Any code suggested by AI should be used as reference and/or thoroughly vetted. At the end of the day, the developer must completely understand any code they submit and its impact to existing features of Tahoma2D. They must be able to debug, modify and test it if any issues arise with it.
